# BehaviorDEPOT Changelog

## v1.7 — 2026-10-15

### Added Functionality

- Automated Keypoint Registration: Persistent detected-part mapping defaults. Confirmed mappings are saved locally
  and prepopulate later registration dialogs when the same detected labels are
  encountered.
- Non-interactive Entry: Expanded automated coverage for noninteractive input validation, explicit batch
  manifests, cue-file processing, ROI configuration, part mapping, and
  desktop-aware dialog placement.

### Changed Functionality

- Updated Keypoint Registration GUI: Redesigned tracked-part registration as a side-by-side mapping interface with
  an example tracking preview and editable known-part dropdowns.
- Updated ROI Selection GUI: Redesigned ROI selection as an integrated frame-and-controls workflow with
  in-panel naming, redraw/delete controls, and analysis cancellation.
- Automated GUI Window Placement and Sizing: ROI selection and part-registration windows now open centered on the active
  display, occupy most of its available area, and remain resizable.
- Single-session Output Naming: Single-session analyzed-output folders use the video filename without its
  extension.
- Deprecated Functionality: Retired compatibility utilities are
  organized under `code/deprecated`.

### Bug Fixes

- Tracking-preview legend labels display spaces instead of underscores.
- Corrected batch cue-name reuse state handling.
- Corrected broad data-exploration metric filtering so the GLM intercept is not
  treated as a metric coefficient.
- Prevented normal analysis/save steps from closing unrelated MATLAB figures.
- Corrected settings import/export behavior in the App Designer interface.
